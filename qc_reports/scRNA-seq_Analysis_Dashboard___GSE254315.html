UMAP Dimensionality Reduction

UMAP — Annotated Cell Types

107,302 cells reduced to 2D. Each colour = one cell type. Points cluster by transcriptional similarity.

How to Read This UMAP

Key biological observations from the embedding

Germ Cell Trajectory
Spermatogonia → Spermatocyte → Early Spermatid → Late Spermatid form a connected developmental trajectory on the UMAP — reflecting the natural progression of spermatogenesis
Somatic Cells Separate Clearly
Sertoli, Leydig, Endothelial, Macrophage and Myoid cells form distinct isolated clusters away from germ cells — confirming clean cell type separation
No Batch Effects
Cells from all 25 samples intermix within each cluster — if batch effects existed, you would see samples clustering separately rather than cell types
Why This Matters for BayesPrism
These 11 annotated cell types become the reference signature matrix. BayesPrism will use these signatures to estimate what proportion of each cell type is present in each of the 14 bulk RNA-seq samples
scRNA-seq Preprocessing Pipeline
1
Data Loading DONE
Reorganised 25 GSE254315 samples into 10X Genomics format (barcodes.tsv.gz, features.tsv.gz, matrix.mtx.gz). Loaded 146,292 cells using Seurat Read10X.
2
Quality Control DONE
Filtered cells: nFeature_RNA >200 & <6000, percent.mt <20%. Removed 38,990 dead cells, empty droplets, and doublets. Retained 107,302 high-quality cells.
3
Normalisation & Feature Selection DONE
LogNormalize (scale factor 10,000). Selected top 2,000 highly variable genes using VST method for downstream dimensionality reduction.
4
PCA + Clustering DONE
50 PCs computed. Louvain clustering (resolution 0.5) on top 20 PCs identified 25 communities (modularity 0.9422). UMAP embedding for visualisation.
5
Cell Type Annotation DONE
25 clusters annotated into 11 cell types using canonical testicular marker genes (SOX9, CYP11A1, MAGEA4, SYCP3, PRM1, PECAM1, CD68, ACTA2, GZMA, RGS5).
6
Reference Matrix Built DONE
107,302 × 32,572 count matrix saved as sc_ref_matrix.rds. Cell type labels saved as sc_cell_labels.rds. Ready for BayesPrism input.
